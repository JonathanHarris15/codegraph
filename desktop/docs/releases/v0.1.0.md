The first release of Codegraph you can install.

Codegraph shows your projects, the codebases in each one, and a map of each
codebase drawn from its code. Sign in with GitHub to put a project online and
work on it with other people at the same time.

## Download

| Your computer | File |
|---|---|
| Mac with Apple silicon (M1 and later) | `Codegraph-0.1.0-mac-arm64.dmg` |
| Mac with Intel | `Codegraph-0.1.0-mac-x64.dmg` |
| Windows | `Codegraph-0.1.0-windows-setup.exe` |
| Linux | `Codegraph-0.1.0-linux-x86_64.AppImage` |

## The first time you open it

The installers are not signed yet, so your computer will warn you once.

- **Mac:** open the `.dmg` and drag Codegraph into Applications. Open it once;
  macOS says it can't check it. Go to **System Settings → Privacy & Security**,
  scroll down, and click **Open Anyway** next to Codegraph. If it says the app
  is damaged instead, run this in Terminal and open it again:
  `xattr -cr /Applications/Codegraph.app`
- **Windows:** run the setup file. If SmartScreen says it protected your PC,
  click **More info**, then **Run anyway**.
- **Linux:** make the file runnable (`chmod +x Codegraph-*.AppImage`) and open it.

## What you need

- **git**, which Codegraph uses to read your repos.
- **Node.js**, only if you want to connect Claude Code to Codegraph's MCP.
- A **GitHub account** to sign in and work with others. Without one, it works
  on this computer alone.
